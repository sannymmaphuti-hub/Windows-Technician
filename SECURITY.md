# Security Policy

## Windows Technician v0.3

Windows Technician is a diagnostic and troubleshooting project designed to analyze Windows system information, collect diagnostic evidence, identify potential technical issues, analyze relationships between diagnostic findings, prioritize issues, determine probable root causes, and provide recommendations.

## Reporting a Security Vulnerability

If you discover a security vulnerability in this project, please report it privately to the project maintainer before publicly disclosing the issue.

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* The affected component or file
* Potential impact
* Any suggested mitigation

Do not include passwords, private keys, personal information, or other sensitive data in a vulnerability report.

## Supported Version

| Version | Supported |
| ------- | --------- |
| v0.3    | Yes       |

## Security Considerations

Windows Technician v0.3 is intended for diagnostic purposes.

The software should be run with appropriate user permissions and should not be granted elevated privileges unless a feature specifically requires them.

Diagnostic results should be reviewed by the user or technician before taking corrective action.

The diagnostic system should not be treated as an automated authority for making system changes. Recommendations should be evaluated before implementation.

## Responsible Disclosure

Security vulnerabilities should be reported responsibly so they can be investigated and addressed before public disclosure.
