# Developer Guide

## Purpose

Explain how developers work safely inside the Windows Technician codebase.

## Scope

- Repository structure
- Development environment
- Architecture boundaries
- Testing
- Integration testing
- Packaging
- Production runtime
- Documentation
- Code quality
- Safe changes

## Development principle

Prefer extending an existing canonical boundary over introducing a parallel implementation.

## Testing principle

Changes should be validated with focused tests followed by the relevant integration or regression gate.
